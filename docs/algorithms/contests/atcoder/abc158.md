## A - Station and Bus

### Problema

Há três estações, cada uma operada pela empresa A ou pela empresa B, descritas por uma string S de comprimento 3. Haverá uma linha de ônibus entre cada par de estações operadas por empresas diferentes. Determine se existe pelo menos uma linha de ônibus.

### Solução

```c
#include <stdio.h>

int main() {
    char s[4];
    scanf("%s", s);

    if (s[0] != s[1] || s[1] != s[2]) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }

    return 0;
}
```

### Explicação

Existe uma linha de ônibus sempre que as três estações **não** são da mesma empresa, ou seja, quando há pelo menos dois caracteres diferentes em S.

### Complexidade

| Métrica | Complexidade |
| :------ | :----------- |
| Tempo   | O(1)         |
| Espaço  | O(1)         |

## B - Count Balls

### Problema

Bolas são colocadas em fila repetindo o seguinte processo: primeiro A bolas azuis, depois B bolas vermelhas. Determine quantas bolas azuis existem entre as N primeiras bolas da fila.

### Solução

```c
#include <stdio.h>

int main() {
    long long n, a, b;
    scanf("%lld %lld %lld", &n, &a, &b);

    long long cycles = n / (a + b);
    long long remainder = n % (a + b);
    long long blue = cycles * a + (remainder < a ? remainder : a);

    printf("%lld\n", blue);
    return 0;
}
```

### Explicação

1. A fila se repete em ciclos de `A + B` bolas, cada um com `A` azuis.
2. Os ciclos completos dentro de N contribuem com `(N / (A + B)) × A` bolas azuis.
3. O ciclo incompleto contribui com `min(resto, A)` azuis, pois as azuis vêm primeiro.

Como N, A e B chegam a 10¹⁸, é necessário usar `long long`.

### Complexidade

| Métrica | Complexidade |
| :------ | :----------- |
| Tempo   | O(1)         |
| Espaço  | O(1)         |
