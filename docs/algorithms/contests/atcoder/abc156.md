## A - Beginner

### Problema

Em um site de competições, o rating exibido de um participante é igual ao rating interno se ele participou de 10 ou mais competições. Caso contrário, o rating exibido é o rating interno menos 100 × (10 − N), onde N é o número de competições. Dados N e o rating exibido R, encontre o rating interno.

### Solução

```c
#include <stdio.h>

int main() {
    int n, r;
    scanf("%d %d", &n, &r);

    if (n >= 10) {
        printf("%d\n", r);
    } else {
        printf("%d\n", r + 100 * (10 - n));
    }

    return 0;
}
```

### Explicação

Basta inverter a fórmula: com menos de 10 competições, o rating interno é `R + 100 × (10 − N)`.

### Complexidade

| Métrica | Complexidade |
| :------ | :----------- |
| Tempo   | O(1)         |
| Espaço  | O(1)         |

## B - Digits

### Problema

Dado um inteiro positivo N e uma base K, determine quantos dígitos N tem quando escrito na base K.

### Solução

```c
#include <stdio.h>

int main() {
    int n, k, digits = 0;
    scanf("%d %d", &n, &k);

    while (n > 0) {
        n /= k;
        digits++;
    }

    printf("%d\n", digits);
    return 0;
}
```

### Explicação

Cada divisão inteira por K remove um dígito na base K. O número de divisões até N chegar a zero é a quantidade de dígitos.

### Complexidade

| Métrica | Complexidade |
| :------ | :----------- |
| Tempo   | O(log_K N)   |
| Espaço  | O(1)         |

## C - Rally

### Problema

Há N pessoas em uma reta, a i-ésima na coordenada Xᵢ. Uma reunião será feita em uma coordenada inteira P, e a i-ésima pessoa gasta (Xᵢ − P)² de energia para chegar até lá. Determine a energia total mínima.

### Solução

```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int x[n];
    for (int i = 0; i < n; i++) {
        scanf("%d", &x[i]);
    }

    int min = x[0], max = x[0];
    for (int i = 1; i < n; i++) {
        if (x[i] < min) min = x[i];
        if (x[i] > max) max = x[i];
    }

    int best = -1;
    for (int p = min; p <= max; p++) {
        int total = 0;
        for (int i = 0; i < n; i++) {
            total += (x[i] - p) * (x[i] - p);
        }
        if (best == -1 || total < best) {
            best = total;
        }
    }

    printf("%d\n", best);
    return 0;
}
```

### Explicação

O ponto ótimo está sempre entre a menor e a maior coordenada, então basta testar cada P inteiro nesse intervalo e guardar o menor custo. Com N ≤ 100 e Xᵢ ≤ 100, a força bruta é suficiente.

### Complexidade

| Métrica | Complexidade              |
| :------ | :------------------------ |
| Tempo   | O(N × (máx − mín))        |
| Espaço  | O(N)                      |
