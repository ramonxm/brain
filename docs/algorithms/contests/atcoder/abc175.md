## A - Rainy Season

### Problema

Dada uma string S de comprimento 3, em que cada caractere é `R` (chuva) ou `S` (sol), determine o maior número de dias consecutivos com chuva.

### Solução

```c
#include <stdio.h>

int main() {
    char s[4];
    scanf("%s", s);

    int best = 0, current = 0;
    for (int i = 0; i < 3; i++) {
        current = (s[i] == 'R') ? current + 1 : 0;
        if (current > best) best = current;
    }

    printf("%d\n", best);
    return 0;
}
```

### Explicação

1. Percorra os dias mantendo o tamanho da sequência atual de dias chuvosos.
2. Em um dia de chuva, incremente a sequência; em um dia de sol, zere-a.
3. Guarde o maior valor que a sequência atingiu.

A mesma ideia funciona para strings de qualquer tamanho, sem precisar enumerar as 8 combinações possíveis.

### Complexidade

| Métrica | Complexidade |
| :------ | :----------- |
| Tempo   | O(n)         |
| Espaço  | O(1)         |
