# Inbox

Notas rápidas, sem formato. Esta pasta **não é publicada**: o Docusaurus ignora caminhos que começam com `_`.

Use para capturar enquanto estuda. Depois, na revisão semanal:

1. Releia cada nota e reescreva a ideia com suas palavras.
2. Se ela virar uma ideia própria, crie a nota permanente na seção certa (`yarn new ...`) e ligue-a a pelo menos uma nota existente.
3. Se ela só complementa uma nota existente, incorpore o conteúdo lá.
4. Apague a nota da inbox.

Veja o fluxo completo no [guia de escrita](../../CONTRIBUTING.md).
