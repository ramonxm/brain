Data Structures

A data structure defines how data is organized and, as a result, how much it costs to access, insert, search or remove an element. Choosing the right structure often matters more than optimizing the code itself.

Comparison​

StructureAccessSearchInsertionRemoval
ArrayO(1)O(n)O(n)O(n)
Linked ListO(n)O(n)O(1) at headO(1) at head
StackO(1) topO(n)O(1)O(1)
QueueO(1) frontO(n)O(1)O(1)
Binary Search TreeO(log n)*O(log n)*O(log n)*O(log n)*

* For balanced trees. In the worst case (a degenerate tree), operations degrade to O(n).

Where to start

If you are not yet familiar with Big O Notation, read it first: the table above uses it.
