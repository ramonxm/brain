## A - Beginner

### Problem

On a contest site, a member's displayed rating equals their inner rating if they have taken part in 10 or more contests. Otherwise, the displayed rating is the inner rating minus 100 × (10 − N), where N is the number of contests. Given N and the displayed rating R, find the inner rating.

### Solution

```c
#include <stdio.h>

int main() {
    int n, r;
    scanf("%d %d", &n, &r);

    if (n >= 10) {
        printf("%d\n", r);
    } else {
        printf("%d\n", r + 100 * (10 - n));
    }

    return 0;
}
```

### Explanation

Just invert the formula: with fewer than 10 contests, the inner rating is `R + 100 × (10 − N)`.

### Complexity

| Metric | Complexity |
| :----- | :--------- |
| Time   | O(1)       |
| Space  | O(1)       |

## B - Digits

### Problem

Given a positive integer N and a base K, find how many digits N has when written in base K.

### Solution

```c
#include <stdio.h>

int main() {
    int n, k, digits = 0;
    scanf("%d %d", &n, &k);

    while (n > 0) {
        n /= k;
        digits++;
    }

    printf("%d\n", digits);
    return 0;
}
```

### Explanation

Each integer division by K removes one base-K digit. The number of divisions until N reaches zero is the digit count.

### Complexity

| Metric | Complexity |
| :----- | :--------- |
| Time   | O(log_K N) |
| Space  | O(1)       |

## C - Rally

### Problem

There are N people on a number line, the i-th one at coordinate Xᵢ. A meeting will be held at an integer coordinate P, and the i-th person spends (Xᵢ − P)² stamina to get there. Find the minimum total stamina.

### Solution

```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int x[n];
    for (int i = 0; i < n; i++) {
        scanf("%d", &x[i]);
    }

    int min = x[0], max = x[0];
    for (int i = 1; i < n; i++) {
        if (x[i] < min) min = x[i];
        if (x[i] > max) max = x[i];
    }

    int best = -1;
    for (int p = min; p <= max; p++) {
        int total = 0;
        for (int i = 0; i < n; i++) {
            total += (x[i] - p) * (x[i] - p);
        }
        if (best == -1 || total < best) {
            best = total;
        }
    }

    printf("%d\n", best);
    return 0;
}
```

### Explanation

The optimal point always lies between the smallest and largest coordinates, so it is enough to try every integer P in that range and keep the lowest cost. With N ≤ 100 and Xᵢ ≤ 100, brute force is enough.

### Complexity

| Metric | Complexity          |
| :----- | :------------------ |
| Time   | O(N × (max − min))  |
| Space  | O(N)                |
