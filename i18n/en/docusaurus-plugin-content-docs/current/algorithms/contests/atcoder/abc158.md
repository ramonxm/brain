## A - Station and Bus

### Problem

There are three stations, each operated by company A or company B, described by a string S of length 3. A bus line will connect every pair of stations operated by different companies. Determine whether at least one bus line exists.

### Solution

```c
#include <stdio.h>

int main() {
    char s[4];
    scanf("%s", s);

    if (s[0] != s[1] || s[1] != s[2]) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }

    return 0;
}
```

### Explanation

A bus line exists whenever the three stations are **not** all run by the same company, that is, when S has at least two different characters.

### Complexity

| Metric | Complexity |
| :----- | :--------- |
| Time   | O(1)       |
| Space  | O(1)       |

## B - Count Balls

### Problem

Balls are placed in a row by repeating the following process: first A blue balls, then B red balls. Find how many blue balls there are among the first N balls in the row.

### Solution

```c
#include <stdio.h>

int main() {
    long long n, a, b;
    scanf("%lld %lld %lld", &n, &a, &b);

    long long cycles = n / (a + b);
    long long remainder = n % (a + b);
    long long blue = cycles * a + (remainder < a ? remainder : a);

    printf("%lld\n", blue);
    return 0;
}
```

### Explanation

1. The row repeats in cycles of `A + B` balls, each with `A` blue ones.
2. The complete cycles within N contribute `(N / (A + B)) × A` blue balls.
3. The incomplete cycle contributes `min(remainder, A)` blue balls, since blue ones come first.

Since N, A and B can reach 10¹⁸, `long long` is required.

### Complexity

| Metric | Complexity |
| :----- | :--------- |
| Time   | O(1)       |
| Space  | O(1)       |
