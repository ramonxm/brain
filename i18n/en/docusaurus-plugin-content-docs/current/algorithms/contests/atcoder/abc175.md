## A - Rainy Season

### Problem

Given a string S of length 3, where each character is `R` (rainy) or `S` (sunny), find the maximum number of consecutive rainy days.

### Solution

```c
#include <stdio.h>

int main() {
    char s[4];
    scanf("%s", s);

    int best = 0, current = 0;
    for (int i = 0; i < 3; i++) {
        current = (s[i] == 'R') ? current + 1 : 0;
        if (current > best) best = current;
    }

    printf("%d\n", best);
    return 0;
}
```

### Explanation

1. Walk through the days keeping the length of the current run of rainy days.
2. On a rainy day, extend the run; on a sunny day, reset it.
3. Keep the largest value the run reached.

The same idea works for strings of any length, without enumerating all 8 possible combinations.

### Complexity

| Metric | Complexity |
| :----- | :--------- |
| Time   | O(n)       |
| Space  | O(1)       |
